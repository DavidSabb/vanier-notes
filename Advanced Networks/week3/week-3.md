# Week 3 Advanced Networks Notes

## Monday Lecture - End Devices

* ### Repeaters

    The number of nodes on a network and the length of cable used.

    __Attenuation__: degradation of signal clarity

    Repeaters work against attenuation by repeating signals that they receive on a network

    Physical layer device with 2 parts

*  ### Hub

    __Star topology__

    Multiple repeaters. Will regenerate signals, does not have 1 output, will send to all end devices. All end devices will see the frame, all sharing the bandwidth.

    Active Hub: amplify or repeat signals that pass through them

    Passive Hub: Merely connects cable on a network and provides no signal regeneration

* ### Network Segmentation

    Breaking down of a single network segment into smaller segments.

    Segment: Part of a network that is divided logically or physically from the rest of the network

* ### Bridge

    Works with mac address to determine destination

    Mac address is data link layer - Bridge works on data link layer

    __Broadcast__ frame - frame is destined for all computers on the network
